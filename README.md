# Pyra

Personal AI operating system for Linux, built around Mark-LIII on a Raspberry Pi.

**Now:** Mark-LIII voice assistant + architecture plans for a multi-agent Master, Project OS, device control, and embedded engineering workflows.

**Docs:** start at [`docs/architecture/00_INDEX_AND_EXECUTIVE_SUMMARY.md`](docs/architecture/00_INDEX_AND_EXECUTIVE_SUMMARY.md)

```bash
cd Mark-LIII
python setup.py
python main.py
```

Secrets stay local (`config/api_keys.json` is gitignored).
